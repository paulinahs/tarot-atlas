# Tarot Atlas

A modern tarot web experience that provides interactive card readings, tarot education, and personal reflection tools.

---

## About

Tarot Atlas is a collaborative project focused on creating an accessible and visually engaging tarot experience.

The project combines:

- Custom illustrations
- Interactive tarot spreads
- Card encyclopedia
- Responsive design
- Accessibility-first UX

---

## Project Goals

- Create meaningful tarot reading experiences
- Build a fully responsive website
- Explore animations and micro-interactions
- Apply accessibility best practices
- Prepare for future mobile app deployment

---

## Features

### Current

- Home page

- Tarot card database
- Individual card pages
